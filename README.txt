ARCHIVOS DEL PROYECTO
- index.html: estructura de la aplicación.
- styles.css: diseño visual responsive.
- app.js: consumo de API, carga de personajes, filtros, paginación, imágenes y modal.
- captura_app.png: imagen referencial para el informe.
- S10_TRABAJO_PRACTICO_EXPERIMENTAL_3_GRUPO_14.docx: informe del trabajo.

FUNCIONAMIENTO
La aplicación consulta The Simpsons API desde JavaScript usando fetch().
El endpoint principal utilizado es:
https://thesimpsonsapi.com/api/characters

La página carga los personajes de forma paginada, usa el campo portrait_path para mostrar las fotografías y presenta la interfaz en español.

PASOS PARA SUBIR A GITHUB
1. Crear un repositorio nuevo en GitHub.
2. Subir index.html, styles.css, app.js, README.txt y captura_app.png en la raíz del repositorio.
3. No subir el ZIP como página web; el ZIP solo es para descarga o respaldo.
4. Entrar a Settings > Pages.
5. Seleccionar Deploy from a branch.
6. Seleccionar branch main y carpeta /root.
7. Guardar y esperar la publicación.

AUTORÍA Y ATRIBUCIÓN
