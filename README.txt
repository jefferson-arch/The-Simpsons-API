DESCRIPCIÓN
Aplicación web en español con diseño profesional inspirado en el sitio oficial de The Simpsons API. Presenta un catálogo interactivo de personajes con imágenes, búsqueda, filtros, paginación y ventana de detalles.

ARCHIVOS DEL PROYECTO
- index.html
- styles.css
- app.js
- captura_app.png
- S10_TRABAJO_PRACTICO_EXPERIMENTAL_3_GRUPO_14.docx

ENDPOINT UTILIZADO
https://thesimpsonsapi.com/api/characters?page=1

FUNCIONES PRINCIPALES
- Interfaz completa en español.
- Carga dinámica de personajes.
- Fotografías automáticas desde portrait_path.
- Buscador por nombre u ocupación.
- Filtros por género, estado y disponibilidad de imagen.
- Paginación de 20 personajes por página.
- Ventana de detalles por personaje.
- Diseño adaptable para computadora, tablet y celular.

PASOS PARA SUBIR A GITHUB
1. Crear o abrir el repositorio en GitHub.
2. Subir index.html, styles.css, app.js, README.txt y captura_app.png en la raíz del repositorio.
3. Entrar a Settings > Pages.
4. Seleccionar Deploy from a branch.
5. Seleccionar branch main y carpeta /root.
6. Guardar y esperar la publicación.
