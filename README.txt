INSTRUCCIONES DE USO
1. Abrir el archivo index.html en un navegador web.
2. La aplicación consulta la API pública: https://thesimpsonsapi.com/api/characters
3. Se requiere conexión a internet para cargar la información real y las imágenes.
4. Si no hay conexión, la página muestra datos de demostración para que el diseño no quede vacío.

ARCHIVOS
- index.html: estructura principal de la página.
- styles.css: estilos visuales y diseño responsivo.
- app.js: lógica de consumo de API con fetch(), filtros y modal de detalles.

FUNCIONES IMPLEMENTADAS
- Consulta de personajes desde una API externa.
- Presentación de datos en tarjetas dinámicas.
- Búsqueda por nombre.
- Filtro por género y estado.
- Paginación de resultados.
- Modal con detalles y frases del personaje.
- Manejo de errores con modo demostración.
