Coloca aquí las imágenes locales de personajes si quieres complementar o reemplazar las fotos de la API.

Formatos soportados por el código:
- id.png / id.webp / id.jpg   (ejemplo: 1.png, 16.webp)
- nombre-slug.png / .webp / .jpg / .jpeg
  ejemplos:
  homer-simpson.png
  marge-simpson.webp
  bart-simpson.jpg

Prioridad de carga en la aplicación:
1. Imagen de la API oficial (portrait_path u otros campos)
2. Imágenes locales dentro de img/personajes/
3. Placeholder 🍩 si no existe ninguna imagen

Si quieres que las imágenes locales tengan prioridad, indícamelo y te adapto el código.
